# Updates

Every Asima OS update is the whole system in one signed file (`.aosupd`, about 3 GB). Installing it
never touches your files, apps or settings, and the version you had stays as the backup.

## Getting a new version

1. **Asima Hub** tells you when a new version is out and downloads it (get it once from Asima
   Manager → Home → Get Asima Hub). You can also download the file from the Asima OS website,
   or bring it on a USB stick.
2. Open the file (double-click it, or Asima Updater → Choose a file). **Asima Updater** checks the
   signature, that it's newer and that there is room, then installs it in the background.
3. **Restart.** The start menu shows both versions; the new one starts.

## If something goes wrong

- **It doesn't start**: after three failed starts the computer starts the backup by itself and
  makes it the current version again.
- **The desktop keeps failing** after the login screen: Asima Updater opens by itself and offers
  going back to the backup.
- **You just prefer the old one**: Asima Updater → Versions → Make it the current version, or
  "Start it once" to try it first.

## Tips

- Updates need about 10 GB free. Asima Maintenance → Overview shows the space.
- An update file has an end date (about four months). After it, download a current one.
- Updates from an older version jump straight to the newest one: no need to install every version
  in between.
